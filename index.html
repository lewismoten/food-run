Workflow
  1. Set what you have in On hand.
  2. Check package costs in Prices.
  3. Build a Buy list and save it for shopping.
  4. Check items as you shop. Confirm only what you bought.

Everything is saved locally in your browser. Back up your data periodically.

Food Run plans groceries by cost. It is not nutrition or medical advice and does not check allergens. Follow product labels for storage and cooking.

    Save your data

    Export your complete IndexedDB data as JSON. Save it somewhere outside this browser. Importing replaces all existing app data.

    USB folder sync

    Connect a folder on a USB drive. The app keeps a JSON snapshot there. It checks for changes while this page is open; if both copies changed, it asks before replacing anything.
